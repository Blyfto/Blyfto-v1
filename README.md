# Blyfto V1

Premium light theme mobile web prototype.

The logo in `assets/blyfto-logo.png` is the exact image supplied for this build and is used without modification.

Upload the contents of this folder to the root of your GitHub repository. For GitHub Pages, choose Settings → Pages → Deploy from a branch → main → /(root) → Save.

This is a front end demo. Account creation and verification are demo interactions and are not connected to a production database or identity verification provider.
